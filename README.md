Descrição

Este é o frontend em React.js desenvolvido para a Prova de Conhecimento Técnico da Fortio.
O sistema consome as APIs do backend em Node.js e oferece uma interface moderna para cadastrar, listar, buscar e excluir clientes, além de visualizar a distribuição por segmentos em um gráfico.



Tecnologias utilizadas

React.js

React Router

Material UI

MUI X Charts

Integração com APIs REST do backend (Node.js + PostgreSQL)





Funcionalidades


Tela de Listagem

Exibe todos os clientes em uma tabela.

Permite buscar por ID.

Botão Novo redireciona para cadastro.

Botão Deletar remove cliente da base.

Exibe gráfico de pizza com distribuição por segmento.



Tela de Listagem

Exibe todos os clientes em uma tabela.

Permite buscar por ID.

Botão Novo redireciona para cadastro.

Botão Deletar remove cliente da base.

Exibe gráfico de pizza com distribuição por segmento.

Mostra a logo Gestão Tech ao lado do gráfico.




Tela de Cadastro

Formulário com campos: Nome, CNPJ, Segmento, CEP, Endereço, Número, Bairro, Cidade, Estado.

Formatação automática de CNPJ e CEP.

Botão Salvar envia dados ao backend e retorna para listagem.

Botão Voltar retorna sem salvar.



Requisitos atendidos

Integração completa com APIs do backend.

Cadastro, listagem, busca e exclusão de clientes.

Layout moderno com Material UI.

Gráfico dinâmico de segmentos com MUI X Charts.

Identidade visual personalizada com logo Gestão Tech.
